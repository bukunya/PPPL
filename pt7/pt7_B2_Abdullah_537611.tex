\section{Hasil dan Pembahasan}

Pada praktikum kali ini, mahasiswa akan menguji aplikasi web menggunakan Selenium WebDriver. Selenium WebDriver adalah sebuah alat yang digunakan untuk mengotomatisasi pengujian aplikasi web dengan cara mensimulasikan interaksi pengguna pada browser. Dalam praktikum ini, mahasiswa akan membuat skrip pengujian untuk menguji fungsionalitas web \url{saucedemo.com}. Tujuannya adalah untuk menguji dua user yang berbeda, yaitu "standard\_user" dan "locked\_out\_user", untuk memastikan bahwa aplikasi web berfungsi sesuai dengan yang diharapkan.

\subsection{Persiapan}

Mahasiswa membuat proyek Java pada Intellij IDEA, kemudian menambahkan dependensi Selenium pada file pom.xml. Selain itu, mahasiswa juga menambahkan dependensi JUnit untuk melakukan pengujian unit pada skrip yang dibuat. Berikut adalah konfigurasi pom.xml yang mahasiswa gunakan:

\subsection{Implementasi method validTest}

Method validTest digunakan untuk menguji login dengan user "standard\_user". Dalam method ini, mahasiswa membuka browser, mengakses situs \url{saucedemo.com}, memasukkan username dan password yang benar, kemudian menekan tombol login. Setelah itu, mahasiswa memverifikasi bahwa login berhasil dengan memeriksa apakah elemen tertentu yang hanya muncul setelah login berhasil dapat ditemukan. Berikut adalah implementasi method validTest:

\begin{lstlisting}[style=javastyle]
@Test
    void validTest(){
        driver = new FirefoxDriver();
        driver.get("https://www.saucedemo.com/");
        WebElement userName = driver.findElement(By.id("user-name"));
        userName.sendKeys("standard_user");
        WebElement password = driver.findElement(By.id("password"));
        password.sendKeys("secret_sauce");
        WebElement submit = driver.findElement(By.id("login-button"));
        submit.submit();

        String expectedUrl = "https://www.saucedemo.com/inventory.html";
        Assertions.assertEquals(expectedUrl, driver.getCurrentUrl(), "URL should match inventory page");

        WebElement header = driver.findElement(By.className("title"));
        Assertions.assertEquals("Products", header.getText());

        boolean isCartVisible = driver.findElement(By.className("shopping_cart_link")).isDisplayed();
        Assertions.assertTrue(isCartVisible);
    }
\end{lstlisting}

variabel driver digunakan untuk mengontrol browser, dan method get digunakan untuk membuka situs web. Kemudian, mahasiswa menggunakan findElement untuk menemukan elemen input username dan password, mengisi keduanya dengan sendKeys, dan menekan tombol login dengan submit. Setelah itu, mahasiswa memverifikasi bahwa URL saat ini adalah URL yang diharapkan setelah login berhasil, memeriksa apakah header "Products" muncul, dan memastikan bahwa ikon keranjang belanja terlihat.

\subsection{Implementasi method lockedOutUser}

Method lockedOutUser digunakan untuk menguji login dengan user "locked\_out\_user". Dalam method ini, mahasiswa melakukan langkah yang sama seperti pada validTest, tetapi dengan username yang berbeda. Setelah mencoba login, mahasiswa memverifikasi bahwa login gagal dengan memeriksa apakah pesan error yang sesuai muncul. Berikut adalah implementasi method lockedOutUser:

\begin{lstlisting}[style=javastyle]
    @Test
    void lockedOutuser(){
        driver = new FirefoxDriver();
        driver.get("https://www.saucedemo.com/");
        WebElement userName = driver.findElement(By.id("user-name"));
        userName.sendKeys("locked_out_user");
        WebElement password = driver.findElement(By.id("password"));
        password.sendKeys("secret_sauce");
        WebElement submit = driver.findElement(By.id("login-button"));
        submit.submit();

        WebElement errorElement = driver.findElement(By.cssSelector("[data-test='error']"));
        String errorMessage = errorElement.getText();

        Assertions.assertTrue(errorMessage.contains("Sorry, this user has been locked out"));
    }
\end{lstlisting}

variabel driver, method get, findElement, sendKeys, dan submit digunakan dengan cara yang sama seperti pada validTest. Setelah mencoba login, mahasiswa mencari elemen yang menampilkan pesan error menggunakan findElement dengan selector CSS. Kemudian, mahasiswa memeriksa apakah pesan error yang ditampilkan mengandung teks "Sorry, this user has been locked out" untuk memastikan bahwa login gagal sesuai dengan yang diharapkan.
